Личный голосовой помощник для Windows 10/11. Новая версия колледжного проекта, написанная отдельно от старых экспериментов. Python 3.12, интерфейс Qt, русский язык. Исходный проект в соседней папке не изменялся.

## Запуск

На этом компьютере окружение `.venv` и русская модель Vosk уже подготовлены: достаточно **`start.bat`**. Для работы без интернета выберите Vosk в настройках. Разговорный ИИ требует отдельно запущенного Ollama с моделью; Whisper остаётся дополнительной установкой.

1. Если библиотеки ещё не установлены, запустите `install.bat`. Нужны Python **3.12 x64**, установленный с Python Launcher, и интернет. Библиотеки устанавливаются только в `.venv` этой папки.
2. Запустите **`start.bat`**. Для диагностики: `.venv\Scripts\python.exe main.py`.
3. Команды можно вводить текстом. Кнопка **«Говорить»** записывает одну фразу. `Ctrl+Пробел` делает то же самое, когда окно Пятницы активно.
4. В настройках выберите микрофон и доступный голос Windows. Русский голос должен быть установлен в Windows. Если его нет, программа использует доступный системный голос; текстовые ответы работают всегда.

Микрофон при запуске выключен. **Esc / «Стоп»** отключает приём новых команд и останавливает озвучку. Текущий короткий захват микрофона завершается по тайм-ауту (до 12 секунд); его результат после остановки отбрасывается. Уже запущенное действие эта кнопка не отменяет. «Отмена» отменяет ожидающее уточнение/подтверждение, а «отмена выключения» отменяет системный отсчёт выключения.

Кнопка **«Свернуть в трей»** оставляет приложение работающим. Закрытие окна крестиком завершает приложение. Второй запуск открывает уже работающий экземпляр. Пока идёт действие, выход откладывается до его завершения.

## Голос и работа без интернета

- **Google:** доступен после установки основных библиотек. Запись команды отправляется внешнему сервису распознавания. Для этого режима нужен интернет.
- **Vosk:** запустите `install_offline.bat`. Он скачает официальную небольшую русскую модель (~45 МБ) в `models/`. Выберите **Vosk** в настройках: распознавание работает на компьютере.
- Если официальный сервер Vosk недоступен, доступно закреплённое зеркало Rhasspy: `.venv\Scripts\python.exe tools\download_model.py --mirror`.
- **Фоновое обращение:** после установки модели Vosk нажмите **«Включить Пятница»**. Можно сказать «Пятница, открой браузер» или сначала «Пятница», а затем команду. Фоновые фразы проверяются локально через Vosk; внешнее распознавание используется только после локального распознавания обращения или во время ожидаемого ответа/диктовки. Режим обращения разрешает следующую команду около 20 секунд. Это распознавание фраз с проверкой обращения, а не специализированный акустический детектор ключевого слова.
- **Whisper, опционально:** `install_whisper.bat` ставит `faster-whisper` и загружает модель `small`. Понадобится существенно больше места и времени, чем для Vosk. В настройках выберите Whisper. При обычном запуске модели автоматически не скачиваются. По умолчанию используется CPU; качество и задержка зависят от оборудования и записи.

Помощник приостанавливает приём речи во время своего ответа и выполнения действия. В режиме одной фразы для каждого ответа на уточнение снова нажмите «Говорить». В фоновом режиме ответы на уточнение и диктовка слушаются без повторения имени.

## Сохранность документов

- Все новые документы — в `data/documents`, заметки — в `data/notes`.
- Имена уникальны: существующий файл не обнуляется при создании нового.
- Выбор внешнего XLSX создаёт рабочую копию в `data/documents`; дальнейшие команды меняют копию. Уже находящаяся в этой папке книга редактируется непосредственно.
- Команды Excel работают с **активным листом** книги. Закройте рабочую копию в Excel перед записью. Изменения сохраняются заменой временного файла, предыдущие версии — в `data/backups`.
- «Отмени изменение» отменяет последнее изменение Excel этого сеанса. После перезапуска резервные файлы остаются, но стек отмены не восстанавливается.
- Объединение не выполняется, если из-за него потеряются заполненные ячейки.
- Строки из речи не превращаются в формулы автоматически. Значения вида `1500` записываются числами.
- Редактирование через openpyxl рассчитано на обычные XLSX. Сложные встроенные объекты и отдельные возможности Excel могут не сохраняться в рабочей копии; исходник остаётся отдельно.
- Черновик диктовки сохраняется после каждой фразы. «Заверши диктовку» оставляет черновик; команда сохранения создаёт документ и очищает его.

Напоминания сохраняются после перезапуска. Если приложение было закрыто в назначенное время, пропущенное напоминание появится при следующем запуске. Приложение не пробуждает выключенный или спящий компьютер.

## Приложения и сценарии

Стандартные программы обнаруживаются через PATH, реестр Windows и распространённые пути. Если приложение не найдено, добавьте его в **Настройки → Файлы → Приложения**:

```json
{
  "telegram": "C:/Users/Имя/AppData/Roaming/Telegram Desktop/Telegram.exe",
  "редактор": "D:/Programs/Editor/editor.exe"
}
```

Теперь можно сказать «Открой редактор». В JSON используйте `/` либо экранированные `\\`. Программы не устанавливаются автоматически.

Сценарии задаются на вкладке **«Сценарии и ИИ»**:

```json
{
  "начинаем учебу": ["открой браузер", "открой word", "таймер на 25 минут"]
}
```

Поддерживаются 1–10 шагов: открытие приложений, таймер, громкость. Выключение, произвольные shell-команды и вложенные сценарии не допускаются. Выполнение нескольких действий не является транзакцией: если приложение не найдено, остальные шаги всё равно могут выполниться, результаты отображаются.

## Разговорный ИИ

### Фоновая установка через медленный интернет

`start_ai_download.bat` запускает или возобновляет установку Qwen3 4B (~2,5 ГБ). Загрузка продолжится независимо от чата, с повторными попытками после обрыва связи. Пока установщик работает, он предотвращает автоматический сон Windows, не меняя постоянные настройки питания. Экран может выключаться. Не закрывайте крышку и не выключайте ноутбук; подключите зарядку и оставьте раздачу интернета включённой.

Прогресс: `ai_download_status.bat` или `data/ai-install-status.json`. Журнал: `data/ai-install.log`. Статус `complete` означает, что модель скачана, ответы и перевод проверены, подключение сохранено. После этого перезапустите Пятницу и скажите «Спроси ИИ …». При завершении предотвращение сна снимается автоматически. `stop_ai_download.bat` останавливает установку с сохранением скачанных частей; если сетевой запрос завис, остановка может занять до нескольких минут. После выключения ноутбука запустите `start_ai_download.bat` заново.

Ollama находится в `runtime/ollama`, его модели — в `models/ollama`.

Поддержан HTTP API **Ollama**. Сам сервер и языковая модель не входят в проект.

1. Установите и запустите Ollama, загрузите подходящую вашему компьютеру модель.
2. В настройках укажите адрес, обычно `http://127.0.0.1:11434`, и точное название установленной модели.
3. Используйте `Спроси ИИ …`, последующие вопросы начинайте с `ИИ …`.

ИИ видит последние 12 сообщений сеанса и текущий вопрос. Контекст можно удалить командой «Очисти контекст ИИ». Он не получает автоматически файлы, экран, заметки и буфер обмена. Его ответы не запускаются как действия. Перевод использует тот же настроенный ИИ. При удалённом адресе запросы уходят на указанный сервер; для удалённых серверов следует использовать HTTPS. Встроенной авторизации для такого сервера пока нет.

## Структура

```text
main.py              запуск и единственный экземпляр
friday/ui.py         окно, трей, настройки, история
friday/engine.py     команды, уточнения, диктовка, напоминания, ИИ
friday/speech.py     микрофон, Vosk / Google / Whisper, озвучка Windows SAPI
friday/windows.py    запуск программ, окна, звук, питание
friday/office.py     DOCX / XLSX / TXT и отмена изменений Excel
friday/storage.py    настройки и сохранение данных
tests/               проверки логики без действий на ПК
tools/               установка модели и диагностика
data/                личные данные, создаётся при запуске
```

Настройки — `data/settings.json`, история — `data/history.json`, ошибки — `data/logs/friday.log`. Аудиозаписи на диск не сохраняются. Историю можно отключить в настройках и удалить кнопкой «Очистить историю». Журнал ошибок может содержать пути и технические сведения из исключений, но намеренно не записывает текст каждой команды.

# Готовое приложение EXE

## Мой ПК и студия записи

Во вкладке **Мой ПК** доступны нагрузка CPU/RAM/GPU с историей, характеристики,
состояние батареи, скорость диска/сети и анализ хранилища по категориям.
Анализ запускается вручную, работает в фоне и отменяется кнопкой. Категории — оценка
по путям и расширениям; недоступные файлы и отличие логического размера от занятого
места отмечены отдельно. GPU показывает наиболее загруженный движок, а не среднее
по всем GPU. При отсутствии счётчика показан прочерк.

Режимы: **игровой** — производительность, яркость 100%, снижение приоритета фоновых
браузеров/лаунчеров и выгрузка локальной модели ИИ; **рабочий** — баланс и 70%;
**энергосберегающий** — энергоэффективность, 40%, снижение фоновых приоритетов.
«Ускорить ПК» снижает приоритет подходящих фоновых приложений. Это не обещает
рост FPS или освобождение всей памяти. Закрытие выбранных приложений — отдельная
кнопка с подтверждением, без принудительного завершения. Исходные настройки можно
вернуть кнопкой; сведения восстановления сохраняются между запусками.

Кнопка **Запись** открывает студию. Можно записывать выбранный экран или экран
с камерой в углу, выбрать 720p/1080p и целевые 15/30 кадров/с, поставить паузу.
Фактическая частота зависит от нагрузки и показана в статусе. Микрофон подключается
отдельным флажком; системный звук не записывается. Камера определяется автоматически
и включается только при старте режима с камерой. Результат — MP4 в `data/recordings`.
Запись продолжается при свёрнутом окне; сон/блокировка Windows могут прервать захват.
При низком остатке места запись останавливается для сохранения. Для выхода из приложения
во время записи сначала завершается файл, затем можно закрыть окно повторно.

Голос: «открой мой ПК», «покажи нагрузку ПК», «открой характеристики ПК»,
«открой хранилище», «анализируй диск», «включи игровой режим», «включи рабочий режим»,
«включи энергосберегающий режим», «ускорь ПК», «верни настройки ПК»,
«начни запись экрана», «начни запись экрана и камеры», «пауза записи»,
«продолжи запись», «останови запись».

Новые команды Windows:

- «Открой мне диспетчер задач», «можешь открыть Telegram», «покажи список программ».
  Каталог автоматически собирается из меню «Пуск», ярлыков и App Paths; обновление —
  «обнови список программ». Для переносимых программ без ярлыков задайте путь в настройках
  или используйте «запусти файл название.exe». Совпадения уточняются по номеру.
- «Подними яркость», «спусти яркость на 20», «установи яркость 50 процентов».
  Без числа изменение составляет 10 пунктов. Нужна поддержка драйвера встроенного экрана.
- «Сделай скриншот», «сделай скриншот приложения» — PNG в `data/screenshots`.
  Снимок приложения захватывает видимую область активного окна; защищённое видео
  и перекрытые части окна могут не попасть на снимок.
- «Включи энергосбережение», «включи производительность», «выключи энергосбережение».
  На Windows 11 выбирается режим питания для батареи и сети; выключение возвращает
  сбалансированный режим. Энергоэффективность — режим питания, отдельный переключатель
  Windows «Экономия заряда» эта команда не меняет.
- «Открой мне папку» — уточнение названия; «пожалуйста», «можешь открыть» и другие
  распространённые формы понимаются без ИИ. Для нераспознанного запроса действия
  локальный ИИ предлагает только действие из разрешённого списка. При неясном запросе
  остаётся обычный диалог. Понимание любых возможных фраз не гарантируется.

Использованы API Microsoft: [яркость WMI](https://devblogs.microsoft.com/scripting/use-powershell-to-report-and-set-monitor-brightness/),
[режим питания Windows 11](https://learn.microsoft.com/en-us/windows/win32/api/powrprof/nf-powrprof-powersetuserconfiguredacpowermode).

**Ctrl+Tab дважды за 0,6 секунды** — глобально включить / выключить микрофон.
Можно держать Ctrl и дважды нажать Tab. После звука включения говорите сразу,
без слова «Пятница»; помощник слушает следующие вопросы до отключения.
Работает в других приложениях и при сворачивании окна / в трее, пока Пятница
запущена и ноутбук не спит. Обычное переключение вкладок Ctrl+Tab сохраняется.
Переключение сопровождается звуком и системным уведомлением; показ уведомлений
зависит от настроек Windows и режима «Не беспокоить».

Команды: «открой папку код», «открой файл рейтинг», «запусти файл программа.exe».
Первый поиск строит индекс в фоне; последующие используют сохранённый индекс.
При совпадениях назовите номер, например «два». Программы и скрипты требуют
подтверждения запуска. Область поиска задаётся в настройках, по умолчанию это
рабочий стол, документы и загрузки. Новые файлы: «обнови индекс файлов»;
автообновление запускается при поиске, если прошло пять минут.

После сборки запускайте `dist/Пятница/Пятница.exe`. Python, библиотеки,
локальный движок Ollama и обе модели уже находятся в комплекте.
Переносите всю папку `Пятница`, включая `_internal`, `models` и `runtime`.
Размещайте её в папке с правом записи: данные сохраняются в `data` рядом с EXE.
Личные данные из исходного проекта не включаются в сборку.
Для повторной сборки: `build_exe.bat` (в окружении сборщика нужен PyInstaller).
Проверка готового приложения: `Пятница.exe --self-test`; результат — `self-test.json`.
