# ИИ пятница 1.0 (бета)

Голосовой помощник для Windows: локальный Ollama, Gemini, Groq и OpenAI, управление приложениями и файлами, голосовой ввод, поиск в интернете, чаты и история.

## Установка без Python

Готовый установщик находится в `dist/Friday-AI-1.0-beta-Setup.exe`. Запустите его и:

1. выберите язык установщика: русский, English или Հայերեն;
2. прочитайте и примите условия использования и политику конфиденциальности;
3. выберите компоненты. Ollama и локальная модель предлагаются отдельно и занимают много места;
4. дождитесь установки и запустите ярлык **ИИ пятница 1.0 (бета)** на рабочем столе.

Python и библиотеки устанавливать не нужно. Установщик создаёт ярлык в меню «Пуск» и на рабочем столе. После запуска язык интерфейса можно изменить в **Настройки → Язык**.

Для публикации скачиваемого файла загрузите `Friday-AI-1.0-beta-Setup.exe` в приватный GitHub Release. Исходный код и релизы доступны только владельцу репозитория: [репозиторий Пятницы](https://github.com/happyfox102/---------------).

## Возможности

- голосовой ввод, озвучка Windows/RHVoice и горячая клавиша;
- локальный Ollama и облачные провайдеры Gemini, Groq, OpenAI;
- запуск программ, файлов и папок естественной фразой;
- поиск в интернете с источниками и открытием ссылок;
- яркость, громкость, режимы питания и скриншоты;
- чаты с разделами, временем сообщений, поиском и локальной SQLite-историей;
- мониторинг ПК, сценарии и справка.

## Запуск из исходников

Требуется Windows 10/11 и Python 3.12 x64.

```powershell
install.bat
start.bat
```

Для сборки переносимой папки:

```powershell
build_exe.bat
```

Готовая папка появится в `dist/Пятница`. Переносить нужно всю папку целиком.

## Первый запуск

Откройте **Настройки → Голос**, выберите микрофон и голос. Затем в **Настройки → ИИ** выберите провайдера, сохраните собственный API-ключ и нажмите проверку. Для полностью локальной работы запустите Ollama и выберите его адрес и модель.

История чатов хранится локально в `data/chats.sqlite3`. Ключи и личные данные не добавляются в репозиторий.

## Безопасность

Не публикуйте API-ключи в чатах, скриншотах и репозиториях. Если ключ уже был раскрыт, отзовите его у провайдера и создайте новый.

Подробности функций и ограничений: [OPERATOR_STATUS.md](OPERATOR_STATUS.md).
