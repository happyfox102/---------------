# Пятница — голосовой ИИ-помощник для Windows

Пятница объединяет голосовое управление, локальный ИИ и инструменты Windows в одном приложении. Пользователь ставит задачу обычными словами, ИИ понимает её, а Пятница выполняет действие через безопасные инструменты.

## Возможности

- голосовой ввод и озвучка ответов Windows/RHVoice;
- Ollama, Gemini, Groq и OpenAI;
- запуск программ, файлов и папок;
- поиск в интернете с источниками;
- управление громкостью, яркостью и режимами питания;
- скриншоты, Windows OCR и анализ контекста экрана;
- чаты, разделы и поиск истории в SQLite;
- VPN-настройки, сценарии и панель состояния ПК;
- горячая клавиша для работы в фоне.

## Скачать и запустить готовую версию

Откройте приватный репозиторий: [Пятница на GitHub](https://github.com/happyfox102/---------------).

1. Откройте **Releases** и скачайте архив последней версии.
2. Распакуйте папку целиком в каталог, где разрешена запись.
3. Запустите `Пятница.exe`.
4. В настройках выберите голос и провайдера ИИ.
5. Для облачного ИИ вставьте собственный API-ключ. Ключи не входят в проект и хранятся в защищённом хранилище Windows.

Если раздела **Releases** ещё нет, скачайте проект через **Code → Download ZIP**, распакуйте его и используйте запуск из исходников.

## Запуск из исходников

Требуется Windows 10/11 и Python 3.12 x64.

```powershell
install.bat
start.bat
```

Для сборки переносимого приложения:

```powershell
build_exe.bat
```

Готовая папка появится в `dist/Пятница`. Переносить нужно всю папку целиком.

## Первый запуск

1. Откройте **Настройки → Голос** и выберите микрофон и голос.
2. Откройте **Настройки → ИИ** и выберите провайдера.
3. Нажмите **Проверить выбранный ИИ**, затем сохраните настройки.
4. Скажите или напишите: «Пятница, открой браузер».

История чатов хранится локально в `data/chats.sqlite3`. Пользовательские ключи, история и скриншоты не включаются в GitHub-репозиторий.

## Безопасность

Пятница не содержит API-ключей в исходниках. Перед публикацией ключ необходимо отозвать и создать новый, если он случайно попал в чат, скриншот или репозиторий.
