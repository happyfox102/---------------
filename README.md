# Пятница 2.1.0

**Пятница** — голосовой помощник для Windows, который объединяет диалог с ИИ, управление файлами и приложениями, голосовые команды, поиск в интернете, работу с документами, мониторинг компьютера, VPN, чаты и запись экрана в одном приложении.

Пятница работает как агент: выбранная модель ИИ понимает задачу, а встроенные инструменты выполняют разрешённые действия в Windows. Простые команды выполняются локально без обращения к облачному ИИ.

> Проект находится в бета-тестировании. Перед важными действиями проверяйте выбранный файл, окно и результат операции.

## Скачать и установить

**[Скачать установщик для Windows](https://github.com/happyfox102/---------------/releases/download/v2.1.0/Friday-AI-2.1.0-Setup.exe)** · **[Все релизы](https://github.com/happyfox102/---------------/releases)**

Установщик не требует отдельной установки Python и библиотек.

1. Запустите `Friday-AI-2.1.0-Setup.exe`.
2. Выберите язык установщика: русский, English или Հայերեն.
3. Прочитайте и примите условия использования и политику конфиденциальности.
4. Выберите компоненты и папку установки.
5. После завершения откройте ярлык **Пятница 2.1.0** на рабочем столе или в меню «Пуск».

Ollama устанавливается как дополнительный компонент. Модель Ollama не включена в установщик, потому что занимает несколько гигабайт; после установки её можно добавить отдельно. Для облачных провайдеров понадобится собственный API-ключ.

Исходный код проекта находится в [репозитории GitHub](https://github.com/happyfox102/---------------). Ключи, история чатов, заметки и личные файлы в репозиторий не входят.

## Быстрый старт

1. При первом запуске нажмите **«Войти через Google»** и выберите аккаунт в браузере. Также можно создать локальный профиль с почтой и паролем; для подтверждения адреса настройте отправку кодов через Gmail в окне входа.
2. При следующих запусках войдите тем же способом. История и настройки каждого профиля сохраняются отдельно.
3. Откройте **Настройки → Голос** и выберите микрофон и голос Windows.
4. Откройте **Настройки → ИИ**, выберите Ollama, Gemini, Groq или OpenAI и нажмите проверку.
5. Введите собственный API-ключ, если выбран облачный провайдер.
6. Напишите команду в поле внизу окна и нажмите стрелку отправки. Для голосовой команды нажмите микрофон или используйте `Ctrl+Пробел`.

Аккаунты, проверочные данные, настройки, история и чаты хранятся в локальных базах SQLite. Документы, снимки и видео остаются обычными файлами в папке профиля. Пароли сохраняются только в виде стойких хешей; пароль приложения Gmail защищён средствами Windows. Коды из писем действуют 10 минут. Кнопка восстановления пароля находится на экране входа.

У каждого профиля отдельные настройки, чаты и папка данных `data/profiles/<id>`. Существующие данные Пятницы копируются в первый подтверждённый профиль, а старая копия сохраняется. Менять пользователя можно через значок профиля в верхней части окна. Такое разделение не заменяет отдельные учётные записи Windows: пользователь с доступом к тем же файлам на диске может их прочитать.

### Вход через Google

Кнопка **«Войти через Google»** открывает системный браузер: выберите аккаунт и подтвердите вход. OAuth-клиент Desktop app включён в локальную сборку, поэтому пользователю не нужно вводить Client ID. Если проект Google OAuth работает в тестовом режиме, владелец проекта добавляет доступные адреса в список тестовых пользователей. [Инструкция Google для настольных приложений](https://developers.google.com/identity/protocols/oauth2/native-app).

При первом входе через Google создаётся локальный профиль. Если для этой подтверждённой почты уже есть локальный профиль, Пятница откроет его и привяжет Google автоматически. В профиле также есть команда **значок профиля → Мой профиль → Привязать Google**. Токены Google в SQLite не сохраняются; каждый новый вход подтверждается через браузер.

При самостоятельной сборке положите JSON OAuth-клиента Desktop app в корень проекта под именем `google_oauth_client.json`. Этот файл исключён из Git; скрипт сборки включает в приложение только публичный Client ID, без Client secret.

Примеры первого запроса:

```text
который час
объясни, что такое Python
открой папку Код
сделай скриншот
найди в интернете рецепт бургера
```

## Провайдеры ИИ

### Ollama — локальная работа

Ollama обрабатывает запросы на компьютере и подходит для работы без отправки диалога в облако.

1. Установите Ollama или выберите компонент Ollama в установщике.
2. Установите модель в Ollama, например модель семейства Qwen.
3. В **Настройки → ИИ** укажите адрес Ollama и точное название установленной модели.
4. Выберите провайдера **Ollama (локально)** и сохраните настройки.

Если модель не установлена, Пятница сообщит об этом в чате. Следуйте инструкции Ollama для загрузки подходящей модели.

### OpenAI, Gemini и Groq

В настройках выберите нужного провайдера, укажите доступную вашей учётной записи модель и вставьте новый API-ключ. Кнопка проверки выполняет короткий API-запрос; подписка ChatGPT сама по себе не заменяет оплату API.

Ключ хранится в защищённом хранилище Windows DPAPI в `LocalAppData/FridayAssistant/secrets`, отдельно от переносимой сборки. Пустое поле при сохранении оставляет старый ключ. Флажок удаления стирает сохранённый ключ. На другом компьютере ключ нужно ввести заново.

Выбранный провайдер получает вопрос, контекст текущего диалога и результаты инструментов, которые вы явно запросили. Экран и локальные файлы автоматически не отправляются. При ошибке ключа, квоте или сети подробности появляются в ответе Пятницы.

## Голос и работа в фоне

- Нажмите микрофон или `Ctrl+Пробел` в окне Пятницы, дождитесь готовности и произнесите команду.
- Удерживайте `Ctrl` и дважды нажмите `Tab`, чтобы включить или выключить микрофон даже поверх другой программы.
- Кнопка **По имени** включает обращение «Пятница» перед командой.
- `Esc` останавливает голос в окне приложения.
- В **Настройки → Голос** можно выбрать микрофон, голос Windows и способ распознавания.
- Vosk работает локально. Google Speech Recognition требует интернета.
- Озвучка ответа включается кнопкой **Голос** в заголовке приложения.

## Основные разделы приложения

### Диалог и чаты

**Диалог** показывает ответы Пятницы. Кнопка `+` создаёт новый чат, а старая переписка сохраняется в истории. Иконка лупы открывает боковую панель с поиском и последними чатами.

В **Настройки → Чаты** можно выбрать расположение панели истории слева или справа. История, разделы чатов и сообщения хранятся локально в SQLite-файле `data/chats.sqlite3`.

### Файлы и приложения

Пятница умеет искать и открывать приложения, файлы и папки:

```text
открой диспетчер задач
открой Telegram
открой папку Код
открой файл Рейтинг
обнови список программ
обнови индекс файлов
```

Программы ищутся в каталогах Windows. Папки поиска добавляются во вкладке **Файлы** в настройках. Если найдено несколько совпадений, назовите номер результата. Если сказать только «открой папку», Пятница уточнит название. Запуск исполняемых файлов требует подтверждения.

Агент создаёт, копирует и переименовывает объекты только в разрешённых папках поиска. Удаление перемещает объект в `data/backups/deleted-*`, рядом сохраняется `restore.txt` с исходным путём.

### Документы и диктовка

Примеры команд:

```text
создай Word Отчёт
создай таблицу Бюджет
создай txt План
запиши 1500 в B3
прочитай B3
скопируй B3 в C3
отмени изменение
```

Документы сохраняются в `data/documents`. Внешняя Excel-книга копируется перед изменениями. Кнопка Excel позволяет выбрать активную книгу и лист.

#### Формулы, расчёты и диаграммы

Пятница умеет записывать формулы Excel, заполнять расчётный столбец и строить диаграммы по диапазону. Формулы сохраняются в книге и пересчитываются самим Excel при открытии файла.

```text
сделай сумму из A2:A20 в B2
сумма A2:A20 в B2
рассчитай столбец D как сумму столбцов A и B
рассчитай столбец D как сумму столбцов A и B с 2 по 100
запиши формулу =IF(A2>0,B2/A2,0) в C2
создай диаграмму из A1:B20
создай линейную диаграмму из A1:B20 с названием Продажи за месяц
создай круговую диаграмму из A1:B8
```

Для диаграммы первый столбец диапазона используется как подписи, а остальные столбцы — как значения. Поддерживаются столбчатые, линейные и круговые диаграммы. Диапазон должен содержать заголовок и данные минимум в двух столбцах. Перед каждой операцией создаётся резервная копия, поэтому последнюю операцию можно отменить командой **«отмени изменение»**.

Если нужно выполнить расчёт по неделе или месяцу, подготовьте в таблице отдельные столбцы с датой и нужным периодом, затем укажите диапазон этих строк, например `сделай сумму из C2:C8 в D2` для недели и `сделай сумму из C2:C31 в D2` для месяца. Для сложных условий используйте формулу Excel через команду **«запиши формулу …»**.

Для диктовки скажите **«начни диктовку»**, затем текст. Доступны команды **«новый абзац»**, **«удали последнее слово»**, **«сохрани диктовку в Word»**. Черновик сохраняется автоматически во вкладке **Черновик**.

### Заметки и напоминания

```text
запомни купить молоко
покажи заметки
таймер на 5 минут
через 20 минут напомни сделать перерыв
```

Заметки хранятся локально в `data/notes`. Для срабатывания напоминаний Пятница должна оставаться запущенной, а компьютер не должен переходить в сон.

### Интернет и браузер

```text
найди в интернете рецепт бургера
браузер открой https://example.com
браузер прочитай страницу
браузер найди Learn more
браузер нажми Learn more
```

При поиске Пятница получает результаты, читает страницы и показывает источники со ссылками. Поисковику передаётся поисковый запрос. Доступ к публичным сайтам можно отключить в настройках ИИ.

Команды браузера запускают отдельное окно Edge. Личные вкладки другого окна не управляются. Нажатие на элемент браузера требует подтверждения.

### Экран, OCR и агентские действия

Иконка глаза открывает выбор PNG/JPEG. Windows OCR читает изображение локально и помещает распознанный текст в диалог. Качество зависит от шрифта и размера. Постоянный захват экрана не ведётся.

Команда **«выполни задачу …»** запускает включённые способности агента. Встроенные инструменты включают Browser, Files, System и Automation. Ненужные способности можно отключить в Marketplace.

Опасные изменения требуют отдельного подтверждения в течение 60 секунд. Для мыши и клавиатуры целевое окно должно оставаться активным; смена окна отменяет действие. Агент выполняет до 6 шагов за один цикл, сохранённые сценарии — до 10 разрешённых шагов. `Esc` или команда **«останови задачу»** прекращает дальнейшие шаги.

### Мой ПК

Во вкладке **Мой ПК** отображаются:

- загрузка CPU и оперативной памяти;
- активность GPU, диска и сети;
- процессор, видеокарта, память и версия Windows;
- выбранный диск и распределение занятого места по категориям.

Анализ хранилища запускается после выбора диска. Индикатор показывает ход анализа, крестик отменяет операцию. Недоступные для чтения данные учитываются отдельно.

### Режимы и оптимизация

Доступны три режима:

- **Игровой** — производительность, яркость 100%, снижение приоритетов фоновых процессов и выгрузка ИИ;
- **Рабочий** — сбалансированные параметры, яркость около 70%;
- **Энергосбережение** — энергоэффективность, яркость около 40%.

Голосовая команда: **«включи игровой режим»**. Кнопка-молния снижает приоритет подходящих фоновых приложений. Процессы можно закрыть отдельно после подтверждения. Документы не закрываются принудительно, а рост FPS не гарантируется. Круговая стрелка восстанавливает сохранённые настройки.

### Запись экрана, камеры и скриншоты

Иконка камеры открывает студию записи. Можно выбрать экран, камеру, разрешение, частоту кадров и микрофон. Для начала рекомендуется 720p и 15 кадров/с. Системный звук не записывается.

- Круг начинает запись экрана.
- Камера добавляет изображение камеры в углу.
- Пауза временно останавливает запись.
- Квадрат завершает запись и сохраняет MP4 в `data/recordings`.

Голосовые команды: **«начни запись экрана и камеры»**, **«останови запись»**.

Скриншоты:

```text
сделай скриншот
сделай скриншот приложения
```

Полный экран и активное окно сохраняются в `data/screenshots` в формате PNG.

### Windows и системные параметры

```text
громкость 30 процентов
подними яркость
яркость 50
включи производительность
включи энергосбережение
```

Выключение и переход в сон требуют подтверждения. Набор доступных параметров зависит от оборудования и версии Windows.

### VPN

Во вкладке **VPN** можно создать профиль по адресу Windows VPN или передать конфигурацию внешнему клиенту.

Поддерживаются ключи и ссылки Amnezia `vpn://`, Happ, VLESS, VMess, Shadowsocks, Trojan, Hysteria2, HTTPS-подписки и файлы `.conf`/`.json`. Проверка определяет формат, но не гарантирует доступность сервера.

Для AmneziaVPN или Happ выберите профиль и нажмите **Передать в клиент**. Пятница найдёт установленный клиент или предложит выбрать его EXE. Ссылка передаётся через буфер с подтверждением, файл экспортируется в выбранное место. Подключение выполняется в самом клиенте, поэтому состояние внешнего туннеля Пятнице неизвестно.

Для встроенного Windows VPN укажите имя, IP/домен и IKEv2 или SSTP, добавьте профиль и нажмите **Подключить**. Windows может запросить логин и пароль. Голосовые команды: **«открой VPN»**, **«включи VPN»**, **«выключи VPN»**, **«статус VPN»**.

### Оформление и языки

В **Настройки → Дизайн** доступны фон, акцентный цвет, шрифт, размер текста и плотность интерфейса. Предпросмотр применяется сразу; **Сохранить** запоминает тему, **Отмена** возвращает прежнюю.

В **Настройки → Язык** можно выбрать русский, English или Հայերեն. Лампочка в заголовке запускает пошаговое интерактивное руководство. Подсказки появляются при наведении курсора на иконки.

## Безопасность и ограничения

- Не публикуйте API-ключи в чатах, скриншотах и репозиториях. Если ключ раскрыт, отзовите его у провайдера и создайте новый.
- Облачный провайдер получает только запрос и контекст, которые Пятница отправляет для выбранной задачи.
- Файлы и экран не отправляются автоматически.
- Перед изменением файлов, запуском программ и закрытием процессов Пятница запрашивает подтверждение.
- Результат нажатия мыши или клавиши нужно проверить в целевом окне.
- Сторонние VPN-клиенты, драйверы и оборудование могут работать иначе, чем встроенные инструменты Windows.
- Облачные API могут иметь лимиты, плату и региональные ограничения.

## Где хранятся данные

- `data/chats.sqlite3` — история чатов;
- `data/notes` — заметки;
- `data/documents` — созданные документы;
- `data/screenshots` — снимки экрана;
- `data/recordings` — записи экрана и камеры;
- `data/backups` — резервные копии удалённых файлов;
- `LocalAppData/FridayAssistant/secrets` — защищённые API-ключи.

## Устранение неполадок

**Пятница не слышит голос.** Проверьте микрофон Windows, выберите его в **Настройки → Голос**, убедитесь, что приложение не заблокировано разрешениями и дождитесь сигнала готовности.

**ИИ не отвечает.** Проверьте выбранного провайдера, название модели, интернет и API-ключ. Для локальной работы убедитесь, что Ollama запущена и модель установлена.

**Не найдена папка или программа.** Добавьте нужную папку в **Настройки → Файлы**, затем скажите **«обнови индекс файлов»**. Для приложений используйте **«обнови список программ»**.

**Не работает VPN.** Проверьте формат конфигурации, выбранный профиль и установленный внешний клиент. Для Amnezia/Happ подключение выполняется в их приложении.

**Не запускается запись.** Проверьте наличие камеры, разрешения Windows и свободное место. Начните с 720p/15 кадров в секунду.

Логи приложения находятся в `data/logs/friday.log`.

## Запуск из исходников

Для разработки требуется Windows 10/11 и Python 3.12 x64:

```powershell
install.bat
start.bat
```

Для сборки переносимой папки:

```powershell
build_exe.bat
```

Готовая папка появится в `dist/Пятница`. Переносить нужно всю папку целиком.
