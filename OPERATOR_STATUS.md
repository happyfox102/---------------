# Пятница: возможности и проверка — 20.09.2026

## ИИ

В настройках ИИ можно выбрать Ollama или OpenAI. Один выбранный провайдер используется для диалога, распознавания сложных команд, ответов с интернет-источниками и агента инструментов. Простые команды работают без модели.

Для OpenAI: укажите модель, новый API-ключ, нажмите «Проверить OpenAI» и сохраните настройки. Проверка делает короткий запрос к API. Ошибки доступа, квоты и сети отображаются без вывода ключа. Облачный режим отправляет вопросы, контекст и результаты запрошенных инструментов в OpenAI. Автоматической передачи экрана нет. При отсутствии доступа можно вручную выбрать Ollama.

API-ключ защищён Windows DPAPI в `%LOCALAPPDATA%/FridayAssistant/secrets/openai.bin`, отдельно от исходников, настроек и переносимой сборки. Действует в текущей учётной записи Windows. Для разработки поддерживается OPENAI_API_KEY, если локальный ключ не сохранён. При удалении локального ключа переменная окружения остаётся доступной. Опубликованный в переписке ключ не записывался; его следует отозвать и заменить. Живой запрос с новым ключом пользователя ещё не проверен.

## VPN

Отдельная вкладка VPN содержит два разных способа работы:

- Windows VPN: создание профиля IKEv2/SSTP по IP или домену, системное окно подключения, отключение выбранного профиля, чтение реального состояния и удаление профиля. Нужны протокол и данные авторизации от провайдера. Пароли запрашивает Windows.
- Ключи внешних клиентов: сохранение зашифрованного ключа, распознавание семейства формата, выбор установленного клиента и передача для импорта. Amnezia `vpn://` передаётся AmneziaVPN. VLESS, VMess, Shadowsocks, Trojan, Socks, Hysteria2, ссылки HTTPS-подписок и Happ — Happ. Файлы WireGuard/AmneziaWG `.conf` — AmneziaVPN; JSON определяется по структуре верхнего уровня. Возможность импорта конкретного варианта окончательно проверяет клиент.

Это **не встроенное универсальное VPN-ядро**. Для внешних ключей импорт и включение/выключение туннеля завершаются в клиенте. Запуск клиента не показывается как подключённый VPN; его состояние Пятнице неизвестно. AmneziaVPN обнаружен на этом ноутбуке. Ничего не скачивалось и работающий интернет не переключался.

Ключи хранятся в DPAPI-хранилище, в `data/vpn.json` — только названия и метаданные. Передача ссылки через буфер требует подтверждения; через минуту буфер очищается, если не был изменён. При экспорте конфигурации создаётся обычный файл с ключами в выбранном месте: после импорта удалите его вручную.

Команды: «открой впн», «включи впн», «выключи впн», «статус впн». Используется профиль, выбранный во вкладке. Нет фонового подключения при запуске. Для прямого управления Amnezia/Happ без их окна нужен отдельный этап интеграции ядра/службы; такой возможности эта версия не заявляет.

## Экран, клавиатура и файлы

- Глаз в заголовке: выбрать PNG/JPEG и прочитать текст локальным Windows OCR. Язык зависит от компонентов Windows. Tesseract больше не обязателен на Windows.
- Исправлен SendInput: русский и латинский текст, регистр и пунктуация передаются корректно. Поле проверяется через Windows UI Automation; при неизвестном или защищённом поле ввод блокируется. При смене окна ввод прекращается.
- Клики, прокрутка и клавиши имеют статус «событие отправлено», если результат приложения невозможно доказать. Подтверждение компьютерного действия связано с активным окном; если оно изменилось, команду надо повторить.
- Файловые инструменты используют актуальные папки поиска; запрещены вложенное копирование в себя, изменение корней и служебных папок, небезопасные имена, рекурсивная обработка junction/symlink.
- Удаление переносит объект в `data/backups/deleted-…`. В `restore.txt` указан исходный путь; восстановите объект Проводником. Если безопасное перемещение невозможно, исходник сохраняется и операция завершается ошибкой. Между дисками используйте отдельное копирование.
- Остановленное копирование может оставить неполную копию назначения; исходник сохраняется. Проверьте её вручную перед повтором.

Агент ограничен 6 шагами. Отдельное подтверждение исполняет один ожидающий инструмент, но не возобновляет длинный план автоматически. Это не автономный оператор произвольных приложений: распознавание текста и доступные команды не гарантируют понимание любого интерфейса.

## Остальные функции

Голосовые команды Vosk/Google, локальная озвучка Windows, двойной Ctrl+Tab, файлы и программы, документы Word/Excel/TXT, диктовка, заметки, таймеры, яркость/громкость/питание, панель нагрузки ПК, анализ диска и режимы, запись экрана/камеры/микрофона, скриншоты, поиск сайтов со ссылками и отдельный управляемый Edge сохранены. Игровая оптимизация меняет параметры и приоритеты, но не гарантирует прирост FPS. Системный звук в записи отсутствует. Whisper остаётся дополнительной установкой.

В справке 14 разделов и 26 учебных иллюстраций, включая OpenAI, VPN, OCR, инструменты и восстановление файлов. Снимки сделаны с учебными данными, без личного экрана и камеры. Темы, шрифты и иконки общие; операции с сетью/VPN выполняются в рабочих потоках с полосой ожидания.

## Проверки

- `python -m unittest discover -s tests -q`: 83 теста успешно. Проверены облачный транспорт на имитации HTTP, отсутствие ключа в метаданных, DPAPI, форматы VPN, отсутствие подстановки пользовательских строк в PowerShell, защита файловых операций.
- `python main.py --self-test-design`: проверка настоящих Qt-виджетов, тем, справки, VPN, настроек OpenAI и жизненного цикла способностей. Отчёт: `artifacts/design-check.json`.
- `python tools/check_new_features.py`: реальное шифрование DPAPI; создание, чтение состояния и удаление тестового Windows VPN **без подключения**; Windows OCR на синтетическом изображении; точный Unicode-ввод в собственное тестовое окно. Отчёт: `artifacts/new-features-check.json`.
- Реальное соединение с VPN-сервером не проверялось: пользователь ещё не предоставил VPN-конфигурацию. Нет подтверждения платного OpenAI-запроса с новым действующим ключом.

## Сборка

`python tools/build_exe.py` обновляет `dist/Пятница/Пятница.exe`. Переносите всю папку вместе с `_internal`, `models`, `runtime`. OpenAI требует сети и собственного ключа; Amnezia/Happ — установленного клиента. Ни API-ключи, ни VPN-ключи в сборку не копируются. Пользовательские данные существующей установки не удаляются.
